# P2P Telegram Mini App — v3 demo

Статический учебный макет Telegram Mini App. Все балансы, профили, цены, пополнения и сделки вымышленные и существуют только в браузерной демо-сессии.

## Возможности
- Строгий тёмный интерфейс и отображение Telegram-профиля через Telegram Web App SDK.
- P2P-офферы и локальная история демо-сделок.
- Демо-трейдинг LONG/SHORT без биржи, реальных ордеров, плеча и вывода средств.
- Имитация пополнения от 1 ⭐ или 1 ₽: начисляются только виртуальные PTS. Реальные Telegram Stars и банковские платежи не подключены.
- Статистика профиля: количество сделок, прибыльные/убыточные сделки, условный PnL, оборот, средний объём и открытые позиции.
- USD/RUB = 83 ₽ показан как фиксированный учебный курс. Остальные цены также демонстрационные, live-источники котировок не подключены.

## Запуск
Откройте `index.html` для локального предпросмотра или разместите три файла `index.html`, `styles.css`, `app.js` на HTTPS-хостинге и укажите HTTPS URL в настройках Mini App через BotFather.

## Ограничения и безопасность
Это фронтенд-прототип без backend и базы данных. Статистика и позиции не сохраняются между перезагрузками. `Telegram.WebApp.initDataUnsafe.user` используется только для визуального предпросмотра профиля; это не аутентификация. Для настоящей авторизации требуется backend-проверка подписи `initData`. Не добавляйте bot token в клиентский код. Не подключены реальные платежи, кошельки, блокчейн, биржи или внешние котировки.
