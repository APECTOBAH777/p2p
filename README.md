# BYBIT Market Simulator v9 — Telegram Mini App + Backend

Это учебный симулятор с сохранённым исходным дизайном. Все деньги, котировки, сделки и предметы виртуальные.

## Что добавлено

- серверная часть на чистом Node.js без внешних npm-зависимостей;
- проверка Telegram Mini App `initData` на сервере через токен бота;
- регистрация игрока в локальной базе `data/db.json` при первом входе;
- поиск зарегистрированных игроков по Telegram username / имени;
- просмотр профиля игрока;
- реальные заявки в друзья между зарегистрированными игроками;
- сохранение виртуального баланса, активов, истории сделок, маркеров графика и коллекции;
- серверная проверка виртуальных сделок;
- frontend автоматически подключается к backend, когда открыт внутри Telegram.

## Локальный запуск

Нужен Node.js 18+.

1. Скопируйте `.env.example` в `.env`.
2. В `.env` укажите токен Telegram-бота:

```text
TELEGRAM_BOT_TOKEN=123456789:xxxxxxxxxxxxxxxx
```

3. Запустите:

```bash
npm start
```

4. Откройте `http://localhost:3000`.

В обычном браузере интерфейс остаётся в демо-режиме. Реальная авторизация и поиск игроков работают при открытии Mini App из Telegram.

## Подключение к Telegram

1. Создайте бота через BotFather.
2. Получите токен бота.
3. Не вставляйте токен в `app.js` или `index.html`.
4. Разместите этот проект на сервере с HTTPS.
5. Настройте у бота кнопку/menu button на URL вашего Mini App.
6. Откройте игру через Telegram.

Telegram передаст Mini App `initData`. Frontend отправляет его в `/api/auth`, а сервер проверяет подпись с помощью `TELEGRAM_BOT_TOKEN`.

## Важное ограничение поиска Telegram

Приложение ищет не произвольных пользователей Telegram, а пользователей, которые уже открыли/зарегистрировали эту игру. Это намеренно: обычный Telegram Bot API не даёт безопасного публичного поиска любого пользователя по username с выдачей произвольных данных профиля.

## API

- `POST /api/auth` — авторизация Telegram и регистрация игрока
- `GET /api/me` — текущий игрок и сохранённое состояние
- `GET /api/players/search?username=...` — поиск игроков
- `GET /api/players/:id` — профиль игрока
- `POST /api/friends/request` — заявка в друзья
- `GET /api/friends` — друзья и входящие/исходящие заявки
- `POST /api/friends/:requestId/accept` — принять заявку
- `POST /api/state` — сохранить игровое состояние
- `POST /api/trades` — серверная регистрация виртуальной сделки
- `GET /api/health` — проверка сервера

## Размещение

Проект можно разместить на любом Node.js-хостинге, который даёт HTTPS и позволяет запускать `npm start`. В качестве базы для небольшой игры сейчас используется `data/db.json`; для большой нагрузки её лучше заменить на PostgreSQL.

## Безопасность

- токен Telegram хранится только на сервере;
- `initData` проверяется на сервере;
- frontend не считается доверенным источником баланса;
- проект не принимает реальные деньги и не подключается к реальной бирже.
