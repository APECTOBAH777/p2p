# ByBit Market Simulator Demo v7

Обновлённый фронтенд учебного симулятора с оранжевой айдентикой ByBit-inspired.

## Состав
- `index.html`
- `styles.css`
- `app.js`
- `README.md`

## Исправления v7
- Обновлён бренд в шапке и заголовке, оранжевая иконка B.
- Добавлена версия к URL CSS/JS (`?v=7`), чтобы браузер не использовал старые закешированные файлы.
- Подключение CSS/JS сделано относительными путями `./styles.css` и `./app.js`, подходящими для GitHub Pages в корне репозитория.
- Добавлены базовые стили в HTML как резерв на случай задержки загрузки CSS.
- Сохранена адаптивная сетка и мобильная навигация.

## Важно
Это неофициальный учебный демо-проект, не связанный с Bybit и не являющийся её официальным приложением. Название используется только как запрошенное оформление. Котировки, пользователи, объявления, чаты и операции синтетические/локальные. Нет реальной торговли, ставок, денежных переводов, платежей или вывода средств.

## Публикация на GitHub Pages
Загрузи все 4 файла в корень репозитория и согласись заменить старые. Проверь, что `index.html`, `styles.css` и `app.js` лежат рядом, а не во вложенной папке. После публикации открой страницу в приватной вкладке или сделай жёсткое обновление страницы.
