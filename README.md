# NORTH Market Simulator v6

Telegram Mini App / GitHub Pages frontend demo.

## Что добавлено
- Переработанный тёмный интерфейс и адаптивная навигация.
- Терминал учебной торговли: выбор BTC, ETH, TON, USDT, USD, EUR; свечной и линейный график; интервалы; виртуальные покупки и продажи; портфель и история.
- P2P-лента с рейтингом вымышленных участников, количеством актива, ценой, модальным подтверждением, локальным чатом.
- Расширенный виртуальный маркет: автомобили, недвижимость, одежда, украшения и техника.
- Профиль: виртуальное состояние, баланс, портфель, имущество, статистика и демонстрационные друзья.
- Локальное сохранение состояния в браузере.

## Важно
Это исключительно учебный симулятор. Котировки синтетические и генерируются локально, не являются реальными рыночными данными. Все пользователи, рейтинги, объявления, сделки и чаты вымышленные и хранятся только в браузере. Нет реальной торговли, денежных переводов, платежей, ставок, вывода средств или подключения к бирже. P2P-покупки выполняются только на виртуальный баланс.

Для Telegram Mini App используется Telegram WebApp SDK только для отображения имени пользователя. `initDataUnsafe` не является подтверждённой авторизацией. Для настоящей авторизации нужен сервер с проверкой `initData`; токен бота нельзя помещать в HTML/JS или публичный репозиторий.

## Запуск
Откройте `index.html` локально или разместите все файлы в корне GitHub Pages.
