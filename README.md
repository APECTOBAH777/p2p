# NORTH — Telegram Mini App (v4)

Статический учебный интерфейс P2P/трейдинга. Баланс 15 000 ₽, пополнение и позиции полностью виртуальные. Реальных платежей, торговли, криптокошелька, серверной авторизации и базы данных нет.

## Публикация
Загрузите `index.html`, `styles.css`, `app.js` в корень GitHub-репозитория и включите GitHub Pages.

## Telegram
Откройте бота через Telegram Mini App. Интерфейс отображает имя/username из `Telegram.WebApp.initDataUnsafe` только как визуальную персонализацию. Это НЕ защищённая авторизация: для проверки личности нужна серверная валидация `initData`.

## Важно
Не добавляйте токены бота, пароли или секреты в этот репозиторий. Не используйте виртуальные балансы как реальные деньги.
