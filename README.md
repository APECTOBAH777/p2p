# NORTH P2P DEMO

Демонстрационный Telegram Mini App на HTML/CSS/JS.

## Запуск
Откройте `index.html` локально или разместите файлы в корне репозитория GitHub Pages.

## Что есть
- Главная с приветствием и Telegram-профилем (если приложение открыто внутри Telegram).
- Отдельный рынок с демонстрационными курсами и сгенерированными объявлениями.
- Кошелёк с условным начислением виртуальных RUB / Stars.
- Профиль, локальная статистика и список демонстрационных друзей.

## Важно
Это только UI-прототип. Онлайн, курсы, пользователи, заявки, сделки, начисления и статистика симулируются в браузере. Нет реальных платежей, реального P2P, кошельков, ордеров, AI-сервера, базы пользователей или доступа к поиску Telegram-пользователей. Соотношение 1 Star = 1000 виртуальных RUB — условное тестовое значение, не курс Telegram и не стоимость звезды.

`initDataUnsafe` используется только для показа имени в демо-интерфейсе. Нельзя применять его для авторизации или финансовых действий без серверной проверки `Telegram.WebApp.initData`.
