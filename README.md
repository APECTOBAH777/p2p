# ByBit Market Simulator Demo v8

Адаптивный учебный симулятор с интерфейсом в тёмной теме и оранжевыми акцентами, вдохновлённый визуальной подачей референса пользователя. Это самостоятельный демонстрационный проект, не официальный продукт Bybit.

## Файлы
- `index.html` — структура приложения
- `styles.css` — адаптивный дизайн для телефона и компьютера
- `app.js` — логика интерфейса и демо-функциональность
- `README.md` — инструкция

## Публикация на GitHub Pages
1. Распакуйте архив.
2. Загрузите все четыре файла в корень репозитория, заменив предыдущие.
3. В GitHub откройте Settings → Pages и проверьте, что выбраны Deploy from a branch, ветка `main`, папка `/ (root)`.
4. Откройте адрес Pages. Для принудительного обновления используйте приватную вкладку или добавьте `?v=8` к адресу.

## Важно
- Все балансы, котировки, покупки, продавцы, рейтинги и чаты виртуальные.
- Нет реальных денег, пополнений, выводов, платежей, реальных ордеров или связи с настоящими пользователями.
- Котировки генерируются локально и не являются рыночными данными.
- Для публикации не добавляйте токены ботов, пароли, ключи API или персональные данные.
