# NORTH P2P Demo v5
Загрузите все файлы в корень репозитория GitHub Pages.

Разделы: главная, P2P-рынок (12 симулированных объявлений, обновление раз в минуту), трейдинг (синтетические графики USD/BTC/ETH/TON с шагом 5 или 10 секунд и фиксацией визуальной точки), магазин виртуальных автомобилей/недвижимости/одежды/предметов, кошелёк с тестовым начислением, профиль/история/демо-друзья.

Это фронтенд-симулятор: реальные котировки, сделки, платежи, Telegram-поиск и серверная база не подключены. Онлайн и профили случайные. 1 Star = 1000 виртуальных ₽ — условный игровой коэффициент, не курс Telegram Stars. initDataUnsafe применяется только для показа имени, не для авторизации. Не помещайте токен бота в публичный репозиторий.
